登录与权限基础

本系统按账号分配功能权限。登录后，你只能看到自己有权使用的菜单，没有权限的功能不会出现，也无法操作。

▸ 怎么登录
  1. 打开系统网址，进入登录页。
  2. 输入管理员分配给你的账号和密码，点击登录即可，之后无需再做其他操作。
▸ 登录后能看到什么
左侧菜单只显示你有权限的功能；不同账号看到的菜单可能不一样。
▸ 关于"数据范围"（权限的一种）

每个账号可以设置不同的数据查看范围，决定你能看到多少数据，共有四种：

  1. 本人：只能看自己负责的数据。
  2. 本部门：能看到本部门的全部数据。
  3. 本部门及下属部门：能看到本部门及其下属部门的全部数据。
  4. 全公司：能看到公司全部数据。
这个"数据范围"只影响「任务」和「项目管理（商机）」两个模块；经营驾驶舱和指标类页面按公司整体口径展示，不受它限制。
▸ 注意事项
账号或密码错误时，系统统一提示"账号或密码错误"；账号被停用后无法登录。你可以在"偏好"里调整页面的行高，让表格看起来更紧凑或更宽松。
1

核心指标 · 年度目标

这一页用来录入和查看公司的年度经营目标完成情况，包括整体目标、各类监控指标，以及各项目公司的指标。数据在「指标」菜单维护，结果直接在本页查看。

▸ 操作流程
  1. 在左侧菜单点击「指标」，进入核心指标页面。
  2. 页面上方用月份选择器切换你想查看的统计周期。
  3. 录入公司整体目标：在「年度目标」「累计完成值」「回款」等列直接填写数字（需要录入权限），单元格变黄后点击该行「保存修改」。
  4. 页面下方还有两块：指标监控（填写当期快照值，如运营车辆数）和项目公司指标（按项目公司分行录入目标与实际，可新增/编辑/删除公司）。
▸ 你能看到的结果
系统自动计算完成率、回款率，并用状态标签标注： 已达成领先偏慢滞后未录入。 标签含义：已达成=目标完成；领先=进度快于时间进度；偏慢/滞后=进度落后于时间进度；未录入=还没填数据。
▸ 注意事项
删除项目公司前，系统会提示关联的目标、任务、账号数量；如果已被其他数据引用，则不能直接删除。部门/班组人员在此页看不到独立的目标数据，页面会给出相应说明。
2

经营驾驶舱

经营驾驶舱用图形方式展示市场项目的商机分布和车辆需求预测，帮助一眼看清全局。数据主要来自「项目管理」里登记的商机，结果在驾驶舱以漏斗和表格呈现。

▸ 操作流程
  1. 在左侧菜单点击「经营驾驶舱」，选择统计周期、组织视角，可按二级部门筛选。
  2. 查看「市场项目概览」三张漏斗：项目数 / 车头需求 / 挂车需求，点击阶段标签可切换查看不同阶段的分布。
  3. 查看「车辆需求分析」：左表看车头需求（按车型×电池容量汇总），右表看挂车需求（按车型汇总）。
  4. 如需调整预测口径，有相应权限的人员可在右上「转化概率配置」里修改各阶段的转化率，保存后全系统生效。
▸ 你能看到的结果
每个阶段展示当前数量、转化率、项目数、车头/挂车数；系统给出加权销量预测（车头、挂车，整数辆）= 各项目需求 × 该阶段转化概率之和；「预估消化数量」= 总需求 × 转化概率，四舍五入取整。

▸ 注意事项
阶段依次是：项目导入 → 市场尽调 → 初审通过 → 联合评审通过 → 签约落地 → 交车投运；另有「流失」阶段转化率 0%，不计入销量预测，也不出现在销售漏斗中。电池容量选项来自系统字典（400 / 423 / 600 / 352 度）。
3

项目管理（商机）

这里用来登记和跟踪市场项目（商机），是经营驾驶舱车辆需求数据的来源。项目在「项目管理」页面维护，列表和详情里查看结果。

▸ 操作流程
  1. 在左侧菜单点击「项目管理」，可用关键词或阶段筛选、分页浏览。
  2. 点击「新建」登记项目：填写名称、描述、项目进展（必填）、车头需求（车型×电池容量×数量）、挂车需求（车型×数量）、阶段、责任人、部门。
  3. 登记后可在详情页追加「进展」记录，记录会按时间顺序展示。
  4. 点击「导出」可下载数据；点击「导入」可按模板批量录入。
▸ 你能看到的结果
项目列表展示名称、进展、阶段、车头/挂车数量、责任人、部门、创建人、时间；详情页有进展时间轴；车头/挂车数量由明细自动汇总。
▸ 注意事项
阶段可选「流失」，表示该项目未成交；删除项目会同时清除它的进展与需求明细，请谨慎操作。
4

任务管理

这里用来登记和跟踪日常工作任务的完成情况。任务在「任务管理」页面维护，列表里直接查看进度与状态。

▸ 操作流程
  1. 在左侧菜单点击「任务管理」，支持平铺或按部门分组查看，可按关键词、部门、状态筛选。
  2. 点击「新建任务」：选择任务组（可现场新增/改名/删除）、填写责任人、是否异常、目标/已完成/单位、计划起止、描述、进展。
  3. 在任务上点击「+ 进展」追加进度记录；「导出 / 导入」走下载中心或模板。
▸ 你能看到的结果
列表展示完成进度、状态、剩余天数、异常标记、责任人、部门；系统自动判定状态： 已完成异常/风险临期正常逾期。 页面还会汇总各部门的任务完成度。
▸ 注意事项
系统内置一个"未分组"任务组，不能删除；任务进展以时间轴方式追加，修改任务本身不会改变已记录的进展历史。
5

数据字典

数据字典是系统里各类下拉选项的"总目录"，例如车型、电池容量、文档分组等。它在「设置 — 数据字典」查看和维护。

▸ 操作流程
  1. 在「设置 — 数据字典」查看各字典及其选项值。
  2. 有相应权限的人员可编辑选项值（整份替换），或对已有选项「停用 / 启用」。
▸ 你能看到的结果
每个字典展示编码、名称、状态（启用/停用）和选项列表。
▸ 注意事项
已经存在的选项不能删除，只能停用；停用后该选项不再出现在相关下拉框。常用字典包括：车型、挂车型号、电池容量（400 / 423 / 600 / 352 度）、文档分组（默认文档 / 用户文档 / 开发文档）。
6

系统管理（账号 / 组织 / 角色）

这里管理系统的使用者、部门架构和权限角色。相关操作都在「设置 — 账号管理」里完成。

▸ 操作流程
  1. 「设置 — 账号管理」有三个页签：账号、组织结构、角色权限。
  2. 账号页签：新增账号填写姓名、登录账号、密码、部门、角色、数据范围（必填）、状态；可启用/停用；删除前会检查是否被引用。
  3. 组织结构页签：新增/编辑部门，形成部门层级。
  4. 角色权限页签：勾选角色能使用的菜单和功能，并设置该角色默认可看的数据范围。
▸ 你能看到的结果
账号列表可按部门/状态筛选；组织结构树显示部门层级、人数、任务数；角色展示其菜单与功能权限。
▸ 注意事项
数据范围共四种（本人 / 本部门 / 本部门及下属 / 全公司），决定该角色能看哪些任务与项目数据；内置角色不能删除。文档中心还有一个"文档分组可见范围"设置也在角色权限里——勾选「文档中心」菜单后，下方会出现可查看的文档分组（留空=可看全部，勾选=只看所选分组）。
7

下载中心

从各页面导出的文件，统一在下载中心管理和下载。文件在「下载中心」查看和获取。

▸ 操作流程
  1. 在任务、项目等页面点击「导出」，系统会生成一条下载记录（不会立刻下载）。
  2. 进入「下载中心」，找到对应记录，点击「下载」或「删除」。
▸ 你能看到的结果
下载记录表显示文件名、来源、创建人、时间；你只能看到自己导出的记录，也只可下载、删除自己的记录。
8

文档中心

文档中心集中存放各类使用文档，按分组归类，方便随时查阅。文档在「文档中心」菜单查看，管理员可在此维护。

▸ 操作流程
  1. 在左侧菜单点击「文档中心」进入。
  2. 左侧按分组列出文档（分组如：默认文档 / 用户文档 / 开发文档），点击切换查看右侧内容。
  3. 有相应权限的管理员可「新建」文档、「同步最新」（把系统内置文档更新到最新）、「编辑」（修改分组或标题、内容）。
▸ 你能看到的结果
右侧展示所选文档内容；每篇标注分组、版本、更新时间。内置文档包括：使用说明（用户文档）、产品需求文档、技术文档、测试文档、视觉交互文档、Skill 文档、项目开发说明（开发文档）。
▸ 注意事项
文档分两级控制查看权限——先要能进入文档中心，再看角色「文档分组可见范围」允许的分组（留空=全部，勾选=只看所选）。例如某角色只能看"用户文档"分组，就只会看到本使用说明，看不到开发类文档。
