登录与权限基础

通用
▸ 输出方式
  1. 打开系统地址，进入登录页，输入 账号 与 密码（默认管理员 admin / 123456）。
  2. 点击登录，系统下发会话 Cookie（HttpOnly），无需手动携带令牌。
  3. 登录后左侧菜单仅显示当前账号有权限的模块；按钮按角色权限显隐。
▸ 输出结果
  • 进入系统首页（经营驾驶舱或指标页，取决于权限）。
  • 顶部可见当前会计周期与「年度时间进度」。
  • 无权模块在菜单中不可见；越权操作返回 403。
登录失败统一提示「账号或密码错误」，不泄露账号是否存在；停用账号返回 403。可在「偏好」中设置行高（default / high / ultra）。

scope 四档 self 本人dept 本部门dept_sub 本部及下属all 全公司　仅作用于「任务」与「项目管理（商机）」；驾驶舱与指标按角色权限全公司口径开放。

核心指标 · 年度目标

metric.view

模块一 · 公司整体目标

▸ 输出方式
  1. 进入「核心指标 · 年度目标」页（菜单 指标）。
  2. 顶部用 月份选择器 切换统计周期（年度目标按年存储，各月度周期共用）。
  3. 在「年度目标」「累计完成值」「回款」列直接填写（需 metric.edit_company 且为公司视角），改动单元格变黄，点击该行「保存修改」。
▸ 输出结果
  • 表格展示：指标 / 年度目标 / 累计完成值 / 完成率 / 回款 / 回款率 / 状态。
  • 完成率以百分比展示，并标注 vs 时间进度 差值（领先/落后）。
  • 状态用进度徽章： 已达成领先偏慢滞后未录入。
达成状态唯一口径：达成率 ≥1 为「已达成」；达成率÷时间进度 ≥1 为「领先」；0.7~1 为「偏慢」；<0.7 为「滞后」；未录值「未录入」。

模块二 · 指标监控

▸ 输出方式
  1. 同一页面下方「二、指标监控」区块（需 metric.edit 可编辑）。
  2. 在卡片输入框填写当期快照值，点击「保存」。
▸ 输出结果
  • 多列卡片网格，每张显示指标名 / 当期值 / 单位 / 上期值。
  • 无目标值、不判红黄绿灯，仅按当期快照录入（如运营车辆数等期末快照类指标）。

模块三 · 项目公司指标

▸ 输出方式
  1. 「三、项目公司指标」区块，点 + 新增项目公司（需 project.create）。
  2. 填写公司名称、负责人、年度目标（可留空后续补录），保存。
  3. 在表格中为目标/实际/回款列填值，按公司「保存」；可「编辑 / 删除」（需对应权限）。
▸ 输出结果
  • 按项目公司分行的表格，列含各指标目标 / 累计完成 / 达成 / 回款率 及公司完成率。
  • 删除前弹出影响预检：年度目标 N 条、累计完成 N 条、关联任务 N 条、账号 N 个（账号停用不删）。

经营驾驶舱

dashboard.view

市场项目概览 · 三漏斗

▸ 输出方式
  1. 进入「经营驾驶舱」，选择统计周期、组织视角，可选二级部门筛选。
  2. 查看「市场项目概览」三张漏斗：项目数 / 车头需求 / 挂车需求。
  3. 可在阶段筛选标签间切换（带转化率后缀），默认「全部」。
▸ 输出结果
  • 每个阶段展示 当前数量口径（不向上累计）：阶段 / 转化率 / 项目数 / 车头数 / 挂车数。
  • 给出加权销量预测（车头 / 挂车，整数）：各项目需求数 × 该阶段转化概率之和。
  • 部门筛选仅统计该部门负责人名下项目。
阶段：10 项目导入 / 25 市场尽调 / 50 初审通过 / 75 联合评审通过 / 90 签约落地 / 100 交车投运。转化概率默认=阶段值/100，可在「转化概率配置」中修改。

车头需求漏斗（原「车辆需求漏斗」）

▸ 输出方式
  1. 在驾驶舱「市场项目概览」中，以车头需求维度绘制漏斗（Round 31 由「车辆需求漏斗」改名）。
  2. 阶段口径同三漏斗，点击阶段标签筛选。
▸ 输出结果
  • 展示各阶段车头需求数量的漏斗形态，直观看商机在各阶段的转化分布。

车辆需求分析（车头 × 电池容量 / 挂车 × 车型）

▸ 输出方式
  1. 在驾驶舱市场项目概览下找到「车辆需求分析」模块。
  2. 上方阶段筛选标签（含「流失」，置于交车/投运后）点击切换，默认「全部」。
  3. 左右两张表各自独立滚动查看。
▸ 输出结果
  • 左表（车头需求）：按（车辆型号 × 电池容量）组合汇总，列：车辆型号 / 电池容量 / 总需求数(辆) / 预估消化数量(辆)。
  • 右表（挂车需求）：按车型汇总，列：挂车型号 / 总需求数(辆) / 预估消化数量(辆)。
  • 预估消化数量 = Σ(该组合下各项目需求 × 项目阶段转化概率)，四舍五入取整（Round 35）。
  • 表格仅行分割线、无竖线，简洁透亮。

转化概率配置

▸ 输出方式
  1. 驾驶舱右上「转化概率配置」入口（需 dashboard.config）。
  2. 修改 6 个阶段的转化率，整份保存。
▸ 输出结果
  • 全系统共用一份 funnel_config，保存后立即影响三漏斗的加权销量预测。

项目管理（商机）

market.view
▸ 输出方式
  1. 进入「项目管理」，用关键词 / 阶段筛选，列表分页浏览。
  2. 「新建」填写：名称、描述、项目进展（必填）、车头需求（车型 × 电池容量 下拉 × 数量）、挂车需求（车型 × 数量）、阶段、责任人、部门。
  3. 阶段可设为「流失」(0%)；保存后进展按时间轴追加，不可直接改进展快照。
  4. 「导出」生成下载记录；「导入」按模板批量录入。
▸ 输出结果
  • 列表展示：项目ID / 名称 / 进展 / 阶段（含「流失」标签）/ 车头数量 / 挂车数量 / 责任人 / 部门 / 创建人 / 时间。
  • 详情页含进展时间轴，新增进展追加展示。
  • 车头/挂车数量 = 明细 qty 自动汇总；电池容量取自数据字典（400/423/600/352度）。
阶段落库允许值含「流失」(stage=0)，保存为流失时不再报「项目阶段不合法」（Round 34 修复）。删除项目会级联清除进展与需求明细。
4

任务管理

task.view
▸ 输出方式
  1. 进入「任务管理」，支持平铺 / 按部门分组视图，按关键词、部门、状态筛选。
  2. 新建任务：选任务组（可内联新增/改名/删除）、责任人、是否异常、目标/已完成/单位、计划起止、描述、进展。
  3. 在任务上「+ 进展」追加时间轴记录；「导出 / 导入」走下载中心 / 模板。
▸ 输出结果
  • 列表展示：完成进度、状态等级、剩余天数、异常标记、责任人、部门等。
  • 状态由系统判定： 已完成异常/风险临期正常逾期。
  • 「部门任务完成度」汇总各部门 total/done/overdue/risk 与完成率。
任务组唯一键=名称+责任人，系统默认「未分组(TG_NONE)」不可删；进展只能追加，编辑不改进展快照。

数据字典

sys.config.view
▸ 输出方式
  1. 进入「设置 — 数据字典」，查看一级字典及其枚举值。
  2. 编辑枚举值（整份替换）；对已有配置点「停用 / 启用」（需 sys.config.edit）。
  3. 电池容量字典含：400度 / 423度 / 600度 / 352度，被项目管理车头需求下拉消费。
▸ 输出结果
  • 字典卡片展示：编码 / 名称 / 状态（启用/停用） / 枚举值列表。
  • 已存在配置不允许删除，只能启用/停用（Round 31）；停用后枚举不再出现在关联下拉。
常用编码：vehicle_model（车型）、trailer_model（挂车型号）、battery_capacity（电池容量）。

系统管理（账号 / 组织 / 角色）

account.view
▸ 输出方式
  1. 「设置 — 账号管理」三页签：账号 / 组织结构 / 角色权限。
  2. 新增账号填名称、账号、密码、部门、角色与 scope（必填）、状态；启用/停用；删除前预检引用。
  3. 组织结构树新增/编辑部门（市场部 D01、根 CO 锁定不可删）。
  4. 角色权限页从 GET /permissions 拉取权限树勾选配置。
▸ 输出结果
  • 账号列表按部门/状态筛选；删除预检显示被任务/项目/指标/账号引用情况，被引用则阻断。
  • 组织结构树显示部门层级、人数、任务数。
  • 角色权限树展示菜单与按钮权限勾选，内置角色不可删，默认权限自动兜底。
scope 必填四档之一；数据范围仅作用于任务与项目管理（商机）。

下载中心

download.view
▸ 输出方式
  1. 在列表/任务/市场项目页点「导出」，系统不直接下载，而是生成一条下载记录。
  2. 进入「下载中心」，找到对应记录，点「下载」或「删除」。
▸ 输出结果
  • 下载记录表：记录ID / 文件名 / 对象 / 创建人 / 时间 / 操作。
  • 仅本人可见、可下载、可删除（按创建人隔离）。

文档中心（使用说明）

sys.config.view
▸ 输出方式
  1. 进入「系统配置 → 使用说明」，打开文档中心。
  2. 左侧为文档列表（使用说明 / 产品需求文档 / 技术文档 / 测试文档 / 设计文档 / Skill 文档 / 项目开发说明），点击切换。
  3. 管理员可点「同步最新」从源码刷新全部文档，或点「编辑」修改当前文档内容（版本号自动 +1）。
▸ 输出结果
  • 右侧展示所选文档内容：HTML 类（如本使用说明）以富文本渲染，Markdown 类转为排版后的网页。
  • 每篇显示版本与更新时间，内容随系统迭代自动同步至数据库。
本页本身即「使用说明」文档，存于数据库，每次迭代由源码自动更新；其余六类文档同理可在系统内统一查阅。
红线提醒：线下数据库的业务数据除非明确提出，不会自动同步到生产环境；发布仅包含代码与字典等配置默认值。线上验证使用的临时数据会在验证后清除，不污染生产。
