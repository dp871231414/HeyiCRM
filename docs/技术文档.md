## 1. 系统架构

```
┌─────────────────────────────┐         ┌──────────────────────────────────┐
│  前端 (Vue3 + TS + Vite)    │  HTTPS  │  后端 (FastAPI + SQLAlchemy 2.0)  │
│  frontend/dist → backend/   │ ──────▶ │  SQLite 单库 (沙箱托管)           │
│  static/（由部署挂载）       │ ◀────── │  Pydantic v2 校验                 │
└─────────────────────────────┘  Cookie │  RBAC + scope 数据隔离            │
                                        └──────────────────────────────────┘
```

- **前端**：Vue 3 `<script setup>` + TypeScript + Vue Router + Pinia；构建产物 `frontend/dist` 必须 `cp -R` 进 `backend/static/` 后随后端一起部署。
- **后端**：FastAPI，SQLite 单文件库；会话用 HttpOnly Cookie（`access_token`），**注意线上反代会改写 `Authorization` 头，API 鉴权走 Cookie 而非 Bearer**。
- **部署**：`workbuddy_sites_deploy`，`directory=backend/`，`startCmd=bash start.sh`（监听 `$PORT`、0.0.0.0，启动幂等 seed）。

## 4. 关键模块实现

### 4.1 市场项目漏斗 `services/funnel.py`
- `load_probs()`：`configured.get(stage, stage/100.0)`，库未配回落阶段百分比。
- 三漏斗：项目数 / 车头需求 / 挂车需求；`stages[]` 为**各阶段当前数量口径，不向上累计**。
- 加权预测 `forecast{tractor,trailer}` = Σ(需求 × prob)，`round` 取整。

### 4.2 车辆需求分析 `build_demand_analysis`
- 车头按 `(model, battery)` 组合聚合；挂车按 `model` 聚合。
- `digest`（预估消化数量）= Σ(该组合下各项目需求 × 项目阶段 prob)。
- **取整 `_round_half_up`**：`int(x + 0.5)`（half-up，规避内置 `round` 的银行家舍入 2.5→2；Round 35）。
- 阶段集合 `DEMAND_ANALYSIS_STAGES = MARKET_STAGES + [CHURN_STAGE]`，流失 `stage=0`、prob=0 **不进漏斗**。

### 4.3 指标达成状态 `services/achievement.py`
- `progress_tone(rate, time_progress)`：唯一口径
  - `done` rate≥1 ｜ `ahead` ratio=rate/时间进度 ≥1 ｜ `near` 0.7≤ratio<1 ｜ `risk` ratio<0.7 ｜ `none` 未录入。
- `light_of`：红黄绿灯 `green/amber/red/none`（缺目标/实际→none）。
- `time_progress_of(period)`：(年初至数据截至日天数+1)/全年天数。
- 加权达成率 = Σ(rate×weight)/Σweight；回款率并入主行（`family=collection`，默认目标 0.95）。

### 4.4 阶段落库校验 `api/v1/market.py`
- 统一白名单 `ALL_PROJECT_STAGE_VALUES = [10,25,50,75,90,100,0]`（constants.py，Round 34 新增）。
- `_apply_payload` 用其校验，放行 `0`（流失）；非法 stage → 422。
- `_STAGE_LABELS` / importer 同步纳入流失（编辑后 stageLabel 正确回填「流失」）。

### 4.5 数据字典启停 `api/v1/system.py`
- 移除 `delete_dict`；新增 `POST /system/dicts/{id}/status`（`DictStatusIn{status:active|disabled}`）。
- 前端按钮改为「停用/启用」+ 状态徽章；停用的枚举不再出现在关联下拉。
- seed 幂等 upsert：本地注入 `battery_capacity`(400度/423度/600度/352度)，不覆盖线上已配值。

### 4.6 权限与数据范围 `services/scope.py`
- scope 四档作用于**任务 + 市场项目**；驾驶舱/指标全公司口径。
- 默认权限兜底 `DEFAULT_PERMS_FOR_ALL = [task.detail, market.detail, sys.config.view, download.view]`。
