# 示意图：登录页

## 页面结构（ASCII）

```
┌───────────────────────────────────────────────────────────────┐
│                                                               │
│  ┌───────────────────────────┐   ┌────────────────────────┐   │
│  │  品牌视觉区（左）           │   │  登录表单区（右）        │   │
│  │  ├ logo（圆角矩形 40px）    │   │  ├ 标题：账号登录        │   │
│  │  ├ 主标题：合一重卡生态     │   │  ├ 账号输入框           │   │
│  │  │        经营看板（一行）   │   │  ├ 密码输入框           │   │
│  │  ├ 副标题：一句自适应换行    │   │  ├ [登录] 按钮          │   │
│  │  └ 科技感装饰层             │   │  └ 错误提示区           │   │
│  │     （网格底纹/光斑/轨道环） │   │                        │   │
│  └───────────────────────────┘   └────────────────────────┘   │
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

## 功能模块说明

| 区块 | 职责与包含元素 |
|---|---|
| 品牌视觉区 | 展示 logo 与产品名称；纯静态装饰，**不渲染任何业务数据**（未登录不读数据） |
| 登录表单区 | 账号、密码输入与提交；错误提示 |

## 页面状态

| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | 不适用（登录页无业务数据） | — |
| 加载中 | 登录按钮显示 loading 且禁用，防止重复提交 | 提交登录请求期间 |
| 成功 | 由路由跳转到经营驾驶舱 | 凭据正确 |
| 错误 | 表单下方红字：账号或密码错误 / 账号已停用 / 登录已过期，请重新登录 | 401、账号停用、令牌过期 |

## 交互说明

- 「登录」按钮：账号、密码均非空时可点击；请求中禁用。
- 回车键等价于点击登录。
- 密码框支持显示/隐藏切换（可选）。
- 无论账号不存在还是密码错误，提示文案一致（不泄露账号存在性）。
