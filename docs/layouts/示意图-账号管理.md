# 示意图：账号管理

## 页面结构（ASCII）

```
┌───────────────────────────────────────────────────────────────┐
│ 顶栏：页面标题 | 周期 | 组织视角 | 用户菜单                      │
├───────────────────────────────────────────────────────────────┤
│ 页签：[账号] [组织结构] [角色权限]                               │
├───────────────────────────────────────────────────────────────┤
│ 页签·账号                                                       │
│  [关键字搜索] [部门▾] [状态▾]              [+ 新增账号]          │
│  ┌──────────────────────────────────────────────────────────┐ │
│  │ 姓名 | 账号 | 所属部门 | 角色 | 可见范围 | 状态 | 最近登录  │ │
│  └──────────────────────────────────────────────────────────┘ │
├───────────────────────────────────────────────────────────────┤
│ 页签·组织结构                                                   │
│  ┌──────────────────────────────────────────────────────────┐ │
│  │ 全公司（创建二级部门）                                     │ │
│  │  ├ 市场部      [+子部门][编辑][删除]                       │ │

│  │  └ …（11 个二级部门）                                      │ │
│  └──────────────────────────────────────────────────────────┘ │

├───────────────────────────────────────────────────────────────┤

└───────────────────────────────────────────────────────────────┘
```

## 功能模块说明

| 区块 | 职责 |
|---|---|
| 账号页签 | 账号增删改查；所属部门与组织管理一致（不含项目公司）；可见范围四类 + 跟随角色默认 |
| 组织结构页签 | 部门树展示与增删改；全公司下创建二级部门；部门行创建子部门；**不含项目公司维护入口** |
| 角色权限页签 | 角色列表与增删改；编辑界面勾选菜单权限与按钮权限，设置可见范围 |

## 页面状态

| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | 「暂无账号/角色」空态 | 无数据或筛选无结果 |
| 加载中 | 表格 loading | 请求中 |
| 成功 | 列表/组织树正常渲染 | 数据返回 |
| 错误 | 错误提示（重名、删除受阻） | 接口 409 |
| 操作中断 | 删除角色/部门二次确认 | 点删除 |

## 交互说明

- 部门「删除」按钮：有账号或有子部门时禁用（tooltip 说明原因）。
- 角色「删除」：内置角色禁用；角色下有账号时禁用并提示先调整账号角色。
- 角色编辑弹窗：取消父级菜单勾选 → 其下按钮权限自动取消。
- 账号编辑弹窗：可见范围含「跟随角色默认」选项；部门下拉呈层级缩进。
- 无 account.edit 权限：不渲染新增/编辑按钮；无 account.role：不渲染角色页签的编辑入口。
