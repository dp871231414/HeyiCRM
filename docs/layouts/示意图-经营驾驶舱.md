## 功能模块说明

| 区块 | 职责 |
|---|---|
| 分析总结区 | 由规则生成整体结论、亮点、建议；不引入 AI |
| 核心指标区 | 年度目标卡片；收入类含回款行；展示完成率与时间进度对比 |
| 项目公司对比区 | 3 家项目公司横向对比，每行「去维护」跳指标维护页定位 |
| 监控指标区 | 事故/故障/租金减免当月亮化数据，无红绿灯 |
| 部门任务完成度区 | 按部门聚合任务卡，含任务数/已完成/逾期/异常，有风险红边并优先排序 |
| 风险与异常清单 | 汇总风险条目，**位于页面最底部** |

## 页面状态

| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | 「本周期暂无指标数据」空态 | 当前组织无目标/实际值 |
| 加载中 | 骨架屏或 loading 占位 | 首次进入、切换周期/组织 |
| 成功 | 全部区块正常渲染，无 NaN/undefined | 数据返回 |
| 错误 | 顶部错误条 + 重试按钮；不白屏 | 接口失败 |

## 交互说明

- 周期选择：切换后全页数据联动刷新。
- 组织视角：管理员可切换全公司/项目公司；其他角色按可见范围。
- 指标卡点击：打开下钻弹窗（趋势 + 下级拆解）。
- 「去维护」：跳转指标维护页并定位高亮对应行。
- 风险条目点击：定位到对应指标卡或任务。
