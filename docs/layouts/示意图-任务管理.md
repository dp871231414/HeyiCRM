# 示意图：任务管理

## 页面结构（ASCII）

```
┌───────────────────────────────────────────────────────────────┐
│ 顶栏：页面标题 | 周期 | 组织视角 | 用户菜单                      │
├───────────────────────────────────────────────────────────────┤
│ 工具条：[关键字搜索] [责任部门▾] [状态▾]   [导出][导入][新建任务] │
├───────────────────────────────────────────────────────────────┤
│ 任务表（列超宽时左右滑动，冻结列）                               │
│ ┌────┬──────┬──────┬────┬────┬────┬────┬──────┬──────┬────┬────┐│
│ │ID│名称│分类│责任人│部门│目标│已完成│进度│起止│状态│操作││
│ │◀─ 冻结 ──▶│                                     │◀ 冻结▶││
│ └────┴──────┴──────┴────┴────┴────┴────┴──────┴──────┴────┴────┘│
│  分页                                                          │
├───────────────────────────────────────────────────────────────┤
│ 新建/编辑弹窗（字段与列表一致）                                  │
│  任务名称 | 任务分类 | 描述 | 是否异常 | 目标 | 已完成 | 单位      │
│  进展描述 | 计划开始日期 | 计划结束日期 | 责任部门 | 责任人  [保存] │
└───────────────────────────────────────────────────────────────┘
```

## 功能模块说明

| 区块 | 职责 |
|---|---|
| 工具条 | 搜索与筛选；按钮按权限显隐（新建需 task.edit、导入需 task.import、删除需 task.delete） |
| 任务表 | 展示任务全字段；冻结列保证横滑时关键列可见 |
| 弹窗 | 新建/编辑任务；字段名与列表一致（任务名称、任务分类） |

## 页面状态

| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | 「暂无任务」空态 | 无数据或筛选无结果 |
| 加载中 | 表格 loading | 请求中 |
| 成功 | 表格渲染，完成进度/状态由系统计算 | 数据返回 |
| 错误 | 错误提示条 | 接口失败 |
| 操作中断 | 删除前二次确认；取消则不变更 | 点删除 |

## 交互说明

- 无 task.edit 权限：不渲染「新建任务」；无 task.import：不渲染「导入」；无 task.delete：操作列不渲染「删除」。
- 导入：选择 xlsx → 上传 → 若含错误行，弹窗列出「行号 + 字段 + 错误说明」并高亮。
- 状态列取值：已完成 / 逾期 N 天 / 临期 / 正常 / 异常。
- 完成进度由 已完成/目标 计算，只读。
