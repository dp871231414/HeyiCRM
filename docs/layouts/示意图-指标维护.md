# 示意图：指标维护

## 页面结构（ASCII）

```
┌───────────────────────────────────────────────────────────────┐
│ 顶栏：页面标题 | 周期 | 组织视角 | 用户菜单                      │
├───────────────────────────────────────────────────────────────┤
│ 模块一 · 公司整体目标（年度目标）                                │
│ ┌───────────────────────────────────────────────────────────┐ │
│ │ 指标 | 年度目标 | 完成值 | 完成率 | 回款 | 回款率 | 状态    │ │
│ │ 销售收入  [____]  [____]  82.3%   [____]  95.0%  ●        │ │
│ │ ……                                                        │ │
│ └───────────────────────────────────────────────────────────┘ │
├───────────────────────────────────────────────────────────────┤
│ 模块二 · 指标监控（无目标，仅录入当月快照）                       │
│ ┌───────────────────────────────────────────────────────────┐ │
│ │ 指标 | 本期值 | 环比                                        │ │
│ │ 总事故数 [3] 较上月 ↑ …                                     │ │
│ └───────────────────────────────────────────────────────────┘ │
├───────────────────────────────────────────────────────────────┤
│ 模块三 · 项目公司指标（列表化）                                  │
│ ┌───────────────────────────────────────────────────────────┐ │
│ │ 公司 | 运营车辆(目标/完成) | 运营收入(目标/完成) | 回款 |   │ │
│ │      利润(目标/完成) | 完成率 | 达成 | 操作(保存/编辑/删除) │ │
│ │ [+ 新增项目公司]                                           │ │
│ └───────────────────────────────────────────────────────────┘ │
├───────────────────────────────────────────────────────────────┤
│ 页脚：[批量导入] [查看驾驶舱]                                    │
└───────────────────────────────────────────────────────────────┘
```

## 功能模块说明

| 区块 | 职责 |
|---|---|
| 模块一 公司整体目标 | 年度目标与完成值录入；收入类含回款录入与回款率；含完成率与状态 |
| 模块二 指标监控 | 事故/故障/租金减免当月快照录入；无红绿灯 |
| 模块三 项目公司指标 | 项目公司列表化维护，含目标/完成行内录入、增删改 |
| 页脚 | 批量导入、返回驾驶舱 |

## 页面状态

| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | 项目公司模块显示「暂无项目公司，点击新增」 | 无项目公司 |
| 加载中 | 表格 loading | 请求中 |
| 成功 | 三模块正常渲染；未录入项显示「—」 | 数据返回 |
| 错误 | 行内错误提示（数值非法） | 输入非数字 |
| 操作中断 | 删除项目公司二次确认并展示影响面 | 点删除 |

## 交互说明

- 未修改时按钮不可点；修改后行高亮且按钮变「保存修改」。
- 无 metric.edit 权限：输入框只读、无保存按钮。
- 项目公司行：仅管理员与该公司负责人可编辑（`metricEditScope`），其余只读。
- 「查看驾驶舱」返回驾驶舱；驾驶舱「去维护」可反向定位到本页对应行并高亮。
- 时间进度对比：完成率旁展示「vs 时间进度」差值，正数标注跑赢。
