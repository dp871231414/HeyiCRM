> 版本：v1.0（由设计文档拆分独立，汇总至 Round 37）　|　最后更新：2026-10-19　|　系统：heyi-fleet-dashboard
> 配套：技术文档（架构）· 产品需求文档（PRD）· 本档聚焦「交互风格 / 交互规范 / 组件规范」。

## 1. 交互风格（Interaction Style）

### 1.1 设计基调
- **简洁透亮**：浅色为主，留白充足；信息以卡片、表格、徽章承载，避免大段文字。
- **色彩即语义**：状态、结果、风险全部用色彩表达（绿=好/达成，蓝=领先/信息，琥珀=偏慢/提醒，红=滞后/风险，灰=未录入/中性）。
- **权限即界面**：用户只见其权限内的功能，无越权入口；无权限的菜单/按钮直接不渲染。
- **原型驱动**：先看效果再补规范，本档为迭代产物，随实现收敛。

### 1.2 设计令牌（Design Tokens）
| 类别 | 取值 | 说明 |
|---|---|---|
| 背景 | `#f7f8fa`（页面）/ `#ffffff`（卡片） | 卡片加轻阴影区分层级 |
| 主色（品牌蓝） | `#2563eb`（btn/链接/激活态） | 渐变 `from-brand-600 to-brand-400` |
| 文本 | `#0f172a`（正文）/ `#475569`（次要）/ `#94a3b8`（占位） | — |
| 边框 | `#e6e8ec` / `#e2e8f0` | 仅行分割线，无竖线 |
| 状态色 | 绿 `#16a34a` / 蓝 `#1d4ed8` / 琥珀 `#b45309` / 红 `#b91c1c` / 灰 `#64748b` | 见 §3.4 徽章 |
| 圆角 | 卡片 `12px` / 输入控件 `8px` / 徽章 `9999px` | — |
| 间距 | 4 / 8 / 12 / 16 / 24 px 基础栅格 | 卡片内 14–16px，模块间 16–24px |

### 1.3 响应式原则
- 双表（如车辆需求分析）`lg:flex` 横向并排；窄屏（<1024px）退化为上下堆叠。
- 表格统一 `overflow-x-auto` + `min-w-[...]` 保证窄屏可横滚，不挤压列。
- 侧边栏可收起（`w-[232px]` ↔ `w-[64px]`），收起态仅留图标。

## 2. 交互规范（Interaction Spec）

### 2.1 导航与菜单
- 左侧硬编码菜单（`AppLayout.vue` `ALL_MENUS`），与 `router/index.ts` 的 `meta.perm` 双声明、保持一致。
- 含子菜单的项（如「系统配置」）默认展开，点击父级可折叠子项。
- 当前页菜单高亮（品牌蓝渐变 + 阴影）；顶部标题随 `route.meta.title` 联动。
- **文档中心（Round 37）**：独立菜单项（perm `doc.view`），不再挂在「系统配置」下；其下文档按分组（用户文档/开发文档）在左侧列表归类。

### 2.2 列表与筛选
- 列表默认分页；分组视图（如任务组、文档分组）需全量取数。
- 阶段筛选标签带转化率百分比后缀，默认「全部」；点击仅显示该阶段。
- 搜索框支持回车触发；「查询」按钮二次确认。

### 2.3 表单与编辑
- 统一 `label + input/select + 必填*` 布局；必填以红色 `*` 标注，缺省提交就近提示。
- 编辑采用「就地编辑 + 保存/取消」，不离开原视图；危险操作（删除、停用）走 `ModalDialog` 二次确认并展示影响预检。
- 时间/数值字段格式化展示（如 `YYYY-MM-DD HH:MM`、千分位、完成率百分比）。

### 2.4 文档中心交互（Round 37 重点）
- **列表**：左侧按「分组」分块展示（如「用户文档」下仅「使用说明」；「开发文档」下为 PRD/技术/测试/视觉交互/Skill/项目开发说明）；当前账号无可见分组的块不显示。
- **阅读**：右区渲染选中文档——HTML 文档用 `iframe srcdoc`，Markdown 用 `.doc-prose` 排版；顶部展示标题/分组/版本/更新时间/格式徽章。
- **编辑（doc.edit）**：进入编辑态后，内容区**上方**出现「分组」下拉（取自 `doc_group` 字典）与「命名」输入框；修改命名不影响后台文档 key（doc_key 不变），已有链接仍有效；保存时仅 content 变更触发版本号 +1。
- **新建（doc.create）**：弹窗填写命名（必填）、分组（必填，默认「默认文档」）、文档 key（选填，留空自动生成）、格式、内容；提交后回到列表并选中新文档。
- **同步（doc.sync）**：管理员「同步最新」按钮，从 `backend/bundled_docs/` 刷新全部内置文档内容。

### 2.5 反馈与异常
- 成功：`app.toast('已保存')` 轻提示；失败：`app.toast(msg, 'error')` 红字提示，不阻断界面。
- 登录失败统一「账号或密码错误」（不泄露账号是否存在）；停用账号 403。
- 表单校验错误就近显示（如文档 key 非法提示「只能包含小写字母、数字、下划线」）。

## 3. 组件规范（Component Spec）

### 3.1 原子类（frontend/src/assets 或全局样式）
| 类名 | 用途 | 关键样式 |
|---|---|---|
| `.input` | 输入框/下拉 | 边框 `#e2e8f0`、圆角 8px、聚焦品牌蓝环；`!w-*` 可覆盖宽度 |
| `.btn-primary` | 主按钮 | 品牌蓝渐变、白字、圆角、hover 加深 |
| `.btn-ghost` | 次按钮 | 透明底、灰字、hover 浅灰底 |
| `.btn-danger` | 危险按钮 | 红字/红底、禁用态灰 |
| `.btn-sm` | 小尺寸按钮 | 缩小组内边距与字号 |
| `.card` | 卡片容器 | 白底、圆角 12px、轻阴影、内边距 14–24px |
| `.chip` | 标签/徽章底 | 小圆角/胶囊、浅底深字 |
| `.label` | 表单标签 | 小字号、中粗、次要色 |
| `.req` | 必填星号 | 红色 `*` |
| `.th` / `.td` | 表格头/单元格 | 仅行分割线、表头浅灰底、数字列 `font-mono tabular-nums` 右对齐 |

### 3.2 ModalDialog（`components/ModalDialog.vue`）
- 属性：`:open`（受控）、`:title`、`width`（sm/lg）、`@close`；具名插槽 `#footer` 放操作按钮。
- 用于：账号/部门/角色表单、批量导入、删除确认、文档新建。
- 行为：打开时锁定背景滚动，点击遮罩或关闭按钮触发 `@close`。

### 3.3 表格规范
- 仅行分割线（`divide-y`），**无竖线**；表头浅灰底、加粗。
- 数字列右对齐 + 等宽字体；状态列用彩色徽章而非文字。
- 行 hover 浅灰底；空数据展示「暂无…/无可见文档」占位。

### 3.4 状态徽章色板（与后端 `progress_tone` 对齐）
| 状态 | 颜色 | 适用 |
|---|---|---|
| done 已达成 | 绿 `#16a34a` | 达成率 ≥100% |
| ahead 领先 | 蓝 `#1d4ed8` | ratio(达成率/时间进度) ≥1 |
| near 偏慢 | 琥珀 `#b45309` | 0.7 ≤ ratio <1 |
| risk 滞后 | 红 `#b91c1c` | ratio <0.7 |
| none 未录入 | 灰 `#64748b` | 缺目标/实际 |
| disabled 已停用 | 灰底 | 字典/账号停用 |

### 3.5 文档正文排版（`.doc-prose`）
- Markdown 文档经后端转 HTML 后 `v-html` 注入；样式集中在 `DocView.vue` 全局 `<style>`。
- 涵盖 h1–h4、p、ul/ol/li、a、code（行内）、pre（代码块，深色底）、blockquote（引用）、table（带边框）、hr。
- HTML 文档（如使用说明）由 `iframe srcdoc` 自包含渲染，保留其内联样式，不受 `.doc-prose` 影响。

### 3.6 图标
- 侧边菜单图标以内联 SVG（`ICONS` 映射）呈现，无外部图标库依赖。
- 操作按钮优先文字（如「编辑」「同步」「新建」），图标仅作为辅助（如收起菜单）。
