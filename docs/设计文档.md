# 车队经营看板 · 设计文档

> 版本：v1.0（汇总至 Round 36）　|　最后更新：2026-10-18　|　系统：heyi-fleet-dashboard

---

## 1. 设计原则
- **原型驱动 > 文档驱动**：先让系统跑起来，再补设计说明（本档即迭代产物）。
- **简洁透亮**：表格去竖线、仅保留行分割线；卡片化信息块；状态用色彩而非长篇文字。
- **决策可追溯**：关键取舍（如「可保存阶段」与「漏斗阶段」分离）在代码注释与项目记忆中留痕。
- **权限即界面**：菜单/按钮按 RBAC 显隐，用户只见其权限内的功能，无越权入口。

## 2. 信息架构
```
经营驾驶舱（dashboard.view）
  ├─ 分析总结卡
  ├─ 市场项目概览（三漏斗：项目数 / 车头 / 挂车 + 加权销量预测）
  ├─ 车头需求漏斗
  ├─ 车辆需求分析（车头×电池容量 / 挂车×车型，双表）
  └─ 转化概率配置弹窗（dashboard.config）
核心指标 · 年度目标（metric.view）
  ├─ 公司整体目标（表）
  ├─ 指标监控（卡片）
  └─ 项目公司指标（表）
项目管理（market.view）     任务管理（task.view）
系统配置（sys.config.view）
  ├─ 数据字典      ├─ 账号管理      ├─ 下载中心
  └─ 使用说明（文档中心，Round 36 新增）
```

## 3. 导航与权限模型
- 左侧菜单为**硬编码数组**（`AppLayout.vue` 的 `ALL_MENUS`），与路由 `meta.perm` 双声明、保持一致。
- 菜单可见性 = `auth.hasPerm(perm)`；分组还需父级 perm 通过。
- 数据范围（scope）仅作用于**任务**与**项目管理（商机）**；驾驶舱与指标全公司口径。

## 4. 关键交互范式
| 场景 | 交互 |
|---|---|
| 市场漏斗 | 阶段为「当前数量口径」不向上累计；阶段筛选标签带转化率后缀，默认「全部」 |
| 车辆需求分析 | 左右等宽双表、各自独立滚动；仅行分割线；阶段标签含「流失」置于末尾 |
| 指标看板 | 达成率 + 进度状态徽章（已达成/领先/偏慢/滞后/未录入）+ vs 时间进度 |
| 文档中心（Round 36） | 左文档列表 + 右内容区；HTML 文档用 iframe srcdoc 渲染，Markdown 用 v-html 渲染；管理员可「同步最新 / 编辑」 |

## 5. 视觉设计系统（前端）
- **主题**：浅色为主，背景 `#f7f8fa`，卡片 `#ffffff` + 轻阴影；强调色蓝 `#2563eb`。
- **状态徽章**：`done` 绿 `#16a34a` / `ahead` 蓝 `#1d4ed8` / `near` 琥珀 `#b45309` / `risk` 红 `#b91c1c` / `none` 灰 `#64748b`。
- **表格**：`divide-y` 仅行线、无竖线；表头浅灰底；数字列右对齐等宽字体（`font-mono tabular-nums`）。
- **表单**：统一 `.input` / `.btn-primary` / `.btn-ghost` / `.btn-sm` 原子类；必填以红色 `*` 标注。
- **响应式**：双表 `lg:flex` 退化为上下堆叠；表格 `overflow-x-auto` + `min-w` 保证窄屏可横滚。

## 6. 文档中心设计（Round 36）
- **存储**：`system_doc` 表（doc_key 唯一），内容存库，前端按 key 读取。
- **渲染策略**：`fmt=html` 的文档（如「使用说明」）以完整自包含 HTML 经 `iframe srcdoc` 渲染，保留其内联样式；`fmt=markdown` 的文档（PRD/技术/测试/设计/Skill/项目开发说明）经后端 `markdown` 库转 HTML 后 `v-html` 注入 `.doc-prose` 排版容器。
- **更新机制**：源文件放 `docs/`，发布前复制到 `backend/bundled_docs/`，调用 `POST /system/docs/sync` 写入数据库，实现「每次迭代自动更新」。
- **权限**：查看 `sys.config.view`（全员默认可看），编辑/同步 `sys.config.edit`。

## 7. 异常处理与文案
- 登录失败统一「账号或密码错误」，不泄露账号是否存在；停用账号返回 403。
- 表单校验错误就近提示（如电池容量必选字典项、阶段非法拦截）。
- 危险操作（删除项目公司、停用账号）走二次确认弹窗并展示影响预检。
